## ✨ 主要修复

### 问题
百度网盘分享链接解析失败,显示"参数错误(可能缺 bdstoken)"

### 原因
Cookie 中包含 `BAIDUID` 导致百度返回精简页面(49576字节),无法解析 `locals.mset`

### 修复
1. 保护 `bdClnd` 变量不被覆盖
2. 在 `bdToken()` 调用前后保存和恢复
3. 增强日志输出便于调试

### 结果
- ✅ 分享页返回完整内容(73999字节)
- ✅ 成功解析 `locals.mset`
- ✅ 正常转存和下载
