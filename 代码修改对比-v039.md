### 修改 2: bdGetRaw() 方法 (行 2096-2125)

#### 修改前:
```java
String bdGetRaw(String path) throws Exception {
    String url = BD_HOST + path;
    String shareCk = bdShareCookie();
    fileLog("bdGetRaw Cookie长度=" + shareCk.length() + " 内容=" + (shareCk.isEmpty() ? "空" : shareCk.substring(0, Math.min(50, shareCk.length())) + "..."));
    for (int i = 0; i < 6; i++) {
        HttpURLConnection c = (HttpURLConnection) new URL(url).openConnection();
        c.setInstanceFollowRedirects(false);
        c.setConnectTimeout(20000);
        c.setReadTimeout(60000);
        c.setRequestProperty("User-Agent", BD_WEB_UA);
        c.setRequestProperty("Accept", "text/html,application/xhtml+xml,*/*");
        c.setRequestProperty("Accept-Encoding", "identity");
        c.setRequestProperty("Referer", "https://pan.baidu.com/disk/home");
        c.setRequestProperty("Cookie", shareCk);
        int code = c.getResponseCode();
        if (code == 301 || code == 302 || code == 303 || code == 307 || code == 308) {
            String loc = c.getHeaderField("Location");
            c.disconnect();
            if (loc == null || loc.isEmpty()) break;
            url = new URL(new URL(url), loc).toString();
            fileLog("bdGetRaw 302跳转到 " + url);
            continue;
        }
        String t = readText(code >= 400 ? c.getErrorStream() : c.getInputStream());
        c.disconnect();
        fileLog("bdGetRaw 返回 " + code + " 长度=" + t.length());
        return t;
    }
    return "";
}
```

## 修改总结

### 核心逻辑
修复的核心是**保护 `bdClnd` 变量不被意外覆盖**:

1. **问题**: `bdToken()` → `apiBaidu()` → `bdCookie()` 会使用包含 `BAIDUID` 的 Cookie
2. **影响**: 导致后续 `bdLocals()` 使用错误的 Cookie 组合
3. **修复**: 在关键调用前后保存和恢复 `bdClnd` 的值

### 日志增强
- 记录每个阶段的 `bdClnd` 长度变化
- 明确标记是"调用前"还是"调用后"
- 记录请求路径和响应详情

### 向后兼容
- ✅ 不影响其他平台(夸克/UC/123/迅雷)
- ✅ 不改变现有的 API 调用流程
- ✅ 仅增加保护逻辑和日志输出
